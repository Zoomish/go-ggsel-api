# Политика безопасности

## Поддерживаемые версии

Исправления вносятся в актуальный код ветки по умолчанию и в последний тег. Старые теги не получают отдельные backport, если уязвимость не критическая.

## Как сообщить

Сообщайте об уязвимости модуля приватно, через [GitHub Security Advisories](https://github.com/Zoomish/go-ggsel-api/security/advisories/new). Публичный issue для ещё не раскрытой проблемы не открывайте.

В отчёт не включайте API-ключ продавца, sign и token. Опишите версию или коммит, шаг воспроизведения и известный ущерб.

## Куда это не относится

Ошибки и уязвимости самого seller.ggsel.com направляйте в поддержку GGSel. Этот репозиторий отвечает только за модуль `github.com/Zoomish/go-ggsel-api`.
